# Capturas do deck executivo

Estas imagens documentam o deployment publicado do Quetzal e sua configuração
Databricks em 12 de outubro de 2026. Elas são incorporadas em
`docs/quetzal-executive-deck.pptx` pelo script
`scripts/build_executive_deck.py`.

| Arquivo | Conteúdo |
|---|---|
| `command-center.png` | Centro de mando publicado |
| `platform-preflight.png` | Preflight das dependências da plataforma |
| `genie-response-chart.png` | Resposta Genie com visualização |
| `quetzal-iq-sources.png` | Quetzal IQ com pesquisa e fontes |
| `customer-360.png` | Visão 360 de cliente sintético |
| `graph-ontobricks.png` | Grafo operacional e OntoBricks |
| `economic-journey.png` | Fechamento econômico reconciliado |
| `unity-ai-gateway.png` | Model service no Unity Gateway |
| `mobile-command-center.png` | Experiência responsiva móvel |

Os dados de clientes exibidos são sintéticos. Nas capturas do grafo e da
jornada econômica, a identidade humana do operador foi removida da própria
imagem antes da inclusão. Nenhuma credencial, token ou segredo é persistido.
